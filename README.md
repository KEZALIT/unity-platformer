# Unity Platformer

Небольшой 2D-платформер на Unity (C#). Вся игра собирается из кода: в проекте нет ни готовых сцен, ни картинок, ни звуковых файлов — спрайты, уровень и звуки создаются скриптами при запуске.

## Что есть в игре

- бег и прыжок с «временем койота» и буфером нажатия (управление прощает небольшие неточности);
- высота прыжка зависит от того, как долго удерживается кнопка;
- 18 монет, 4 врага (на них можно прыгать сверху), шипы, движущаяся платформа над пропастью;
- чекпоинт, 3 жизни, финишный флаг, счёт и таймер;
- звуковые эффекты, сгенерированные в коде.

## Управление

| Клавиша | Действие |
| --- | --- |
| `A` / `D` или `←` / `→` | бег |
| `Пробел`, `W` или `↑` | прыжок |
| `R` | начать уровень заново |

## Как запустить

1. Установите [Unity Hub](https://unity.com/download) и редактор Unity **2022.3 LTS** или новее (подойдёт и Unity 6).
2. Склонируйте репозиторий:
   ```
   git clone https://github.com/KEZALIT/unity-platformer.git
   ```
3. В Unity Hub нажмите **Add → Add project from disk** и выберите папку репозитория. Если Hub скажет, что нужной версии редактора нет, выберите любую установленную версию не старше 2022.3.
4. При первом открытии проект сам создаст пустую сцену `Assets/Scenes/Main.unity` и добавит её в Build Settings. Если этого не произошло — меню **Platformer → Создать сцену Main**.
5. Нажмите **Play**.

Собрать игру в исполняемый файл: **File → Build Settings → Build**.

### Если герой не двигается

Игра читает клавиатуру через классический `Input`. Если в проекте включена только новая Input System, откройте **Edit → Project Settings → Player → Other Settings → Active Input Handling** и выберите **Both** или **Input Manager (Old)**.

## Структура

```
Assets/
  Scripts/
    GameManager.cs       — запуск игры, счёт, жизни, интерфейс
    LevelBuilder.cs      — описание и сборка уровня
    PlayerController.cs  — управление героем
    Enemy.cs, Coin.cs, Hazard.cs, Checkpoint.cs, Goal.cs, MovingPlatform.cs
    CameraFollow.cs      — камера
    SpriteFactory.cs     — спрайты, нарисованные кодом
    Sfx.cs               — звуки, сгенерированные кодом
    Rigidbody2DCompat.cs — совместимость Unity 2022 и Unity 6
  Editor/
    PlatformerSceneSetup.cs — автоматическое создание сцены
Packages/manifest.json
ProjectSettings/ProjectVersion.txt
```

## Как изменить уровень

Уровень описан в методе `LevelBuilder.Build()` обычными вызовами:

```csharp
AddGround(15f, 27f, 0f);        // земля от x=15 до x=27, верх на высоте 0
AddPlatform(19f, 2f, 3f);       // платформа: левый край, высота верха, ширина
AddEnemy(16.5f, 25.5f, 0f);     // враг ходит между x=16.5 и x=25.5
AddCoin(20.5f, 3f);             // монета
```

Герой прыгает примерно на 2,7 юнита в высоту и на 5,5 юнита в длину — ориентируйтесь на эти числа, расставляя платформы.

Параметры героя (скорость, сила прыжка и т. д.) — публичные поля в `PlayerController.cs`.

## Примечание

После первого открытия Unity создаст рядом со скриптами файлы `.meta` и остальные файлы в `ProjectSettings/`. Их стоит добавить в репозиторий (`git add -A && git commit`), чтобы настройки проекта сохранялись у всех одинаково.
